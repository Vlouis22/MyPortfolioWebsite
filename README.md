# Valery Louis — Portfolio

Personal portfolio site built with Next.js, React, and TypeScript.

**Live site:** https://valerylouis.netlify.app/

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS · Framer Motion · MDX

## Development

```bash
npm install
npm run dev
```

## Updating content

- **Personal info / links:** `src/lib/site.ts`
- **Projects:** `content/projects/`
- **Experience:** `content/experience/`
- **Resume & images:** `public/assets/` and `public/images/projects/`
