## Overview

I built this project to explore how automation and AI could improve the job search experience by collecting listings, organizing them, and surfacing more relevant opportunities.

![Job recommendation system interface](/images/projects/job-recommendation/thumb.svg)

## What I built

The system used automated scraping and recommendation logic to help users discover roles that better matched their interests. I focused on building a pipeline that made the data easier to work with and more useful for personalized suggestions.

<Callout title="Takeaway">
This project showed me that recommendation quality depends a lot on clean data and thoughtful filtering, not just the model itself.
</Callout>

## Results

The project gave me more experience with AI powered workflows, data handling, and building software that helps users make better decisions.
