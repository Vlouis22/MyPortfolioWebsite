## Overview

This project focused on building a peer to peer file synchronization system that could keep files consistent across multiple machines without relying on a central server.

![P2P synchronization system diagram](/images/projects/p2p-sync/thumb.svg)

## What I built

I led a team of 5 and helped organize the system into clear pieces so we could work in parallel without losing track of how everything fit together. The project pushed me to think more carefully about coordination, state management, and debugging in distributed systems.

<Callout title="What I learned">
This was one of the projects that helped me become more comfortable leading a team through a technical problem with a lot of moving parts.
</Callout>

## Results

We delivered a working synchronization system in Python and gained a much stronger understanding of how distributed systems behave under real constraints.
